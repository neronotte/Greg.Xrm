Configure table dialog

This panel allows to select an entity to compare between the two environments.

After choosing an entity you can also select which key should be used to detect whether a specific record is present in both environments or not.
You can choose to use as key for comparison the default GUID of the record, or to build a logical key picking one or more columns of the table.

The dialog allows also to configure which attributes should not be taken in consideration while comparing records, and whether or not consider only active records in the comparison.

FetchXML filter

By default all the records of the table are compared. Clicking on FetchXML filter... you can type a FetchXML query that restricts the set of records to compare. Please note that:

  • The same filter is applied to both environments.
  • Only filters and link-entities are taken into account: all the columns of the table are always compared (except the ones marked as "to ignore"), regardless of the attributes specified in the FetchXML.
  • If only active records is checked, the condition on the record status is applied in AND with the FetchXML filter.
  • The FetchXML must refer to the selected table, and cannot contain the aggregate or top attributes.
  • Use Clear filter (or leave the text empty) to compare all the records again.

You can also build the filter visually with FetchXML Builder, using the Actions > Edit filter with FetchXML Builder... command of the Configurator.
